As Amperlane ops, I want one live board per site for the current day, with bookings by state, each EVSE's status and
its age, and the open exceptions, so that I no longer keep a hand-coloured Google Sheet per site open to know what is
happening there.

## Acceptance criteria

Scenario: S1 · happy path · The board shows the site's day
  Given a site has bookings today
  When an ops user opens the site's board
  Then it shows today's bookings grouped by state
  And each EVSE of the site with its status and the time that status was observed
  And the site's open exceptions

Scenario: S2 · happy path · Changes appear without reloading
  Given an ops user has a site's board open
  When a booking at the site changes state or an EVSE status changes
  Then the board shows the change without the ops user reloading it

Scenario: S3 · failure · A stale status is marked
  Given a connected site whose latest status for EVSE A is older than 60 seconds (constitution N2)
  When an ops user views the site's board
  Then EVSE A's status is marked as stale, with its age

Scenario: S4 · failure · The status feed is down
  Given the site's status feed is unavailable
  When an ops user views the site's board
  Then every EVSE's status is marked as stale, with its age
  And the site's open exception for the feed is shown on the board

Scenario: S5 · edge case · LIC status comes from the attendant
  Given the LIC site, whose status comes from the attendant view
  When an ops user views its board
  Then each EVSE shows "last updated by attendant at <time>"

Scenario: S6 · edge case · A site in another time zone
  Given a site in a time zone other than Eastern
  When an ops user views its board
  Then the current day and the times shown follow the site's time zone

## Notes

- Staleness and status age follow constitution N1 and N2 (60 seconds) and REQ-160; a feed outage follows REQ-168
  (FT-05.2). Time zones follow A-013 and REQ-151. LIC status depends on the attendant view (U-13; A-021, Q-049).
- The pilot's per-site Google Sheet is the tool this replaces (CTX-042).
