As Amperlane ops, I want a printable QR code for each EVSE of a site, so that site staff can post one at every EVSE and
drivers can record their arrival with a scan instead of sharing their location.

## Acceptance criteria

Scenario: S1 · happy path · Ops get one printable code per EVSE
  Given a site with its EVSEs set up in the platform
  When an ops user asks for the site's QR codes
  Then the platform produces one printable QR code for each EVSE of the site
  And each printed code names its site and its EVSE in readable text
  And scanning a code identifies that site and that EVSE

Scenario: S2 · failure · A code the platform did not produce records nothing
  Given a QR code whose content was not produced by the platform, or was altered after it was produced
  When a driver with a booking at the site scans it inside the arrival window
  Then no arrival is recorded on the booking

Scenario: S3 · failure · A user who is not Amperlane ops cannot produce the codes
  Given a fleet manager is signed in to the fleet portal
  When the fleet manager asks for a site's QR codes
  Then the request is refused

Scenario: S4 · edge case · A reprinted code identifies the same EVSE
  Given the code posted at EVSE A was lost
  When an ops user prints the code for EVSE A again
  Then scanning the new code identifies EVSE A at its site

Scenario: S5 · edge case · A new EVSE gets its own code
  Given ops added EVSE C to a live site
  When an ops user asks for the site's QR codes
  Then the codes include one for EVSE C
  And a scan of that code inside a booking's arrival window records arrival for a booking at that site

## Notes

- A-012: site staff or the attendant put up physical items; Amperlane does not staff sites. How the printed codes reach
  site staff is not stated.
- Whether a station operator may print its own sites' codes is not stated; S3 tests only a fleet user.
- Scanning is US-101.
