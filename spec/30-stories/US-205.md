# US-205 · The same booking rules at sites of every supply pattern

As a driver, I want booking, allocation, grace, auto-release, no-show and fault rebooking to work the same way at
Gowanus, JFK and LIC, so that I can book any partner site without learning how each one treats me.

## Acceptance criteria

Scenario: S1 (happy path) The same booking request gets the same answer at each pattern
  Given Gowanus (pattern A), JFK (pattern B) and LIC (pattern C) each have the same capacity rule, booking durations
    and grace period configured for a test window
  And the same compatible vehicle is used at each site
  When the same booking request is made at each site
  Then each site accepts or refuses it with the same result and reason
  And each accepted booking is allocated to one EVSE at the site's allocation offset, not at booking time

Scenario: S2 (happy path) Only the station-hold step differs
  Given an allocated booking at each of the three sites
  When the site's station-hold offset before the slot is reached
  Then at Gowanus a reservable EVSE gets a charger reservation through the CSMS
  And at JFK and at LIC site staff get a station-hold request
  And the booking's state and timers are the same at all three sites

Scenario: S3 (failure) No arrival within grace
  Given an allocated booking at each of the three sites
  And no arrival is recorded at any of them
  When each booking's grace period ends
  Then each booking is released automatically with no human action at the end of its site's grace period
  And each is handled as a no-show by the same rule

Scenario: S4 (failure) A charger fault
  Given each of the three sites has an EVSE with bookings allocated to it later that day
  When that EVSE is reported faulted, by the CSMS at Gowanus and JFK and by the attendant at LIC
  Then the bookings on the faulted EVSE are rebooked by the same fault-rebooking rule at all three sites
  And each rebooked booking carries the same reason code

Scenario: S5 (edge case) A non-reservable EVSE at a pattern A site
  Given a Gowanus booking is allocated to an EVSE not flagged as reservable
  When the site's station-hold offset before the slot is reached
  Then site staff get a station-hold request for it, as at JFK
  And every other step of the booking follows the same rules as for a reservable EVSE

Scenario: S6 (edge case) Status comes from a different source at LIC
  Given the same booking exists at JFK and at LIC
  When ops looks at the status of the allocated EVSEs
  Then JFK's status comes from its CSMS and LIC's from the attendant view
  And the booking rules applied to both bookings are the same
