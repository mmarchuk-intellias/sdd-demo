# US-025 · Station-hold requests to site staff replace the ops phone call

As an attendant at a site without charger reservations, I want the platform to tell me which stall to mark for a
booking, when to mark it and when to clear it, so that I hold the right stall at the right time without ops phoning me.

## Acceptance criteria

Scenario: S1 (happy path) Site staff get the stall, when to mark it and when to clear it
  Given a booking at JFK Lot 9 is allocated to an EVSE that is not flagged as reservable
  When the site's configured station-hold offset before the slot is reached
  Then site staff receive a station-hold request naming the stall to mark, when to mark it and when to clear it
  And the booking's audit trail shows no manual ops action for the station hold

Scenario: S2 (failure) The request cannot be delivered
  Given a station-hold request for a booking cannot be delivered to site staff
  When the set time passes
  Then an ops exception for the booking appears in the ops queue

Scenario: S3 (failure) A booking cancelled before its station hold gets no request
  Given a booking at JFK Lot 9 is cancelled before the site's station-hold offset
  When the station-hold offset would have been reached
  Then site staff get no station-hold request for it

Scenario: S4 (edge) The LIC attendant gets the request in the attendant view
  Given a booking at LIC Garage Depot is allocated
  When the station-hold offset is reached
  Then the attendant sees the stall to mark, when to mark it and when to clear it in the attendant view

Scenario: S5 (edge) A Gowanus EVSE without charger reservations also goes to site staff
  Given a booking at Gowanus FastHub is allocated to an EVSE that is not flagged as reservable
  When the station-hold offset is reached
  Then Gowanus site staff receive a station-hold request for its stall

## Notes

- Depends on: A-012 (site staff do the physical station hold; Amperlane does not staff sites), A-046 and Q-041 (how JFK
  staff receive and acknowledge requests), A-021, Q-010 and Q-049 (the LIC attendant view; U-13: nobody has confirmed
  the attendant will use it; A-054: Hunters Point Garages provides the attendant's device, S4), and A-048 with Q-059
  (how Gowanus site staff receive and acknowledge requests, S5).
- Unacknowledged requests: JS-026 (REQ-156). Clearing the stall when the booking ends: US-027 (REQ-035). An EVSE a
  walk-up is using never gets a request: JS-018 (REQ-020). Running station holds by hand: US-029 (REQ-170).
- "Within the set time" is a configured value; its default is a design detail for Step 3.3.
