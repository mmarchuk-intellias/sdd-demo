# US-311 · Station operator changes a capacity rule and sees walk-up capacity

As a station operator, I want to change a site's capacity rule myself, effective at once, and see for each time window
how many EVSEs stay unbookable for walk-ups, so that I keep enough EVSEs for walk-ups on a busy day, such as a game at
Citi Field, without asking Amperlane first.

## Acceptance criteria

Scenario: S1 (happy path) A lower cap applies to new bookings at once
  Given a site with a weekday afternoon capacity rule
  When the station operator lowers that rule's cap in the station portal
  Then the new cap is in force at once, with no approval step by Amperlane
  And a new hold or booking in that window is accepted only while the window stays within the new cap

Scenario: S2 (happy path) Walk-up capacity per window
  Given a site's capacity rules
  When the station operator opens the site's capacity in the station portal
  Then each time window shows its cap on bookable EVSEs and how many of the site's EVSEs stay unbookable for walk-ups
  And when a cap changes, the walk-up figure of that window changes with it

Scenario: S3 (failure) Overlapping rules are refused
  When the station operator saves a rule whose days and time window overlap another rule of the same site
  Then the rule is not saved and the overlapping rule is named

Scenario: S4 (failure) A cap above the site's EVSEs is refused
  When the station operator sets a cap higher than the number of EVSEs at the site
  Then the rule is not saved

Scenario: S5 (failure) Another station operator's site
  When a station operator tries to change a capacity rule of a site that is not theirs
  Then the request is refused and the rule is unchanged

Scenario: S6 (edge case) A change while the window is under way
  Given the window has already started today
  When the station operator lowers its cap
  Then the new cap applies to new bookings for the rest of that window at once
  And bookings already confirmed stand, as in JS-312
