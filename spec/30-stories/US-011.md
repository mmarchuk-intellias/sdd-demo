# US-011 · An EVSE is never allocated to two overlapping bookings

As a charging driver, I want the EVSE allocated to me never to be allocated to another booking whose time overlaps
mine, buffer included, so that I never arrive to find another booked driver charging on it.

## Acceptance criteria

Scenario: S1 (happy path) Overlapping bookings get different EVSEs
  Given two confirmed bookings at a site whose times overlap
  When both are allocated
  Then they are allocated to different EVSEs

Scenario: S2 (failure) An allocation inside the site's buffer is refused
  Given an EVSE is allocated to a booking
  When another booking that starts less than the site's configured buffer after that booking ends is allocated
  Then it is not allocated to that EVSE
  And it gets another free compatible EVSE, or is handled as a full site (JS-019)

Scenario: S3 (failure) Simultaneous allocations to the same EVSE
  Given two overlapping bookings are allocated at the same moment and the same EVSE is the only free compatible one for both
  When both allocations are attempted
  Then only one of the two bookings gets that EVSE
  And the other is handled as a full site (JS-019)

Scenario: S4 (edge) A booking that ended early no longer blocks the EVSE
  Given an EVSE was allocated to a booking that was then cancelled, released after grace or rebooked to another EVSE
  When another booking overlapping that booking's time is allocated
  Then it can be allocated to that EVSE

Scenario: S5 (edge) Back-to-back bookings exactly one buffer apart
  Given an EVSE is allocated to a booking
  When another booking that starts exactly the site's configured buffer after that booking ends is allocated
  Then it can be allocated to that EVSE
