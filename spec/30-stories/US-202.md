# US-202 · Gowanus session records through AMPECO

As Amperlane finance, I want the record of each charging session at Gowanus read from Kinship's AMPECO API, so that
every Gowanus booking can be settled and counted against the station operator's own record of the charge.

## Acceptance criteria

Scenario: S1 (happy path) A Gowanus session record is read
  Given Kinship has made session records available through the AMPECO API
  And a charging session has ended at a Gowanus EVSE
  When AMPECO makes that session's record available
  Then the platform stores the session record with its EVSE, start, end and energy as AMPECO reports them
  And the record can be retrieved by EVSE and time window for matching to a booking (REQ-161)

Scenario: S2 (failure) The AMPECO API is unreachable when records become available
  Given Kinship has made session records available through the AMPECO API
  And the AMPECO API does not answer for a period
  When sessions end at Gowanus during that period
  Then the platform reads each of those session records once the API answers again
  And no session record from that period is missing

Scenario: S3 (failure) AMPECO returns the same session record again
  Given the platform has stored a Gowanus session record
  When AMPECO returns the same session record again
  Then the platform still holds exactly one record for that session

Scenario: S4 (failure) Kinship has not made session records available
  Given the AMPECO API offers no session records for Gowanus
  When a Gowanus booking ends
  Then the platform stores no session record for it
  And the booking is handled as a booking without a session record (REQ-214)
  And Gowanus status reading and charger reservations keep working (US-201, US-232)

Scenario: S5 (edge case) A session record arrives long after the session
  Given a charging session at Gowanus ended earlier in the day
  When AMPECO makes its record available only hours later
  Then the stored record keeps the session's own start and end as AMPECO reports them
  And the time the platform received the record is stored separately from them
