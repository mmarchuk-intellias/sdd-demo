# JS-023 · Charger reservation rejected or unanswered, booking unchanged

When the charger rejects the charger reservation for my allocated EVSE, or does not answer, I want to have site staff
hold the stall and ops alerted while my booking stays as it is, so I can still find the EVSE held when I arrive.

## Acceptance criteria

Scenario: S1 (happy path) A rejected reservation falls back to site staff and ops
  Given a charger reservation was sent for the allocated EVSE of a booking at Gowanus FastHub
  When the CSMS reports the reservation as rejected
  Then the platform sends site staff a signage request for that EVSE's stall
  And raises an ops exception for the booking
  And the booking stays confirmed and allocated to that EVSE

Scenario: S2 (failure) No answer within the set time
  Given a charger reservation was sent for a booking's allocated EVSE
  When no answer from the CSMS arrives within the set time
  Then the platform sends site staff a signage request for that EVSE's stall and raises an ops exception for the booking
  And the booking stays confirmed

Scenario: S3 (failure) A reservation that expires or is cancelled at the CSMS does not change the booking
  Given a booking whose charger reservation was accepted
  When the reservation expires or is cancelled at the CSMS before the driver arrives
  Then the booking is not released, cancelled or rebooked because of it
  And its grace and auto-release still follow Amperlane's slot calendar

Scenario: S4 (edge) Rejected because a walk-up occupies the EVSE
  Given the charger rejects the reservation and the EVSE's status shows it occupied by a walk-up
  When the platform handles the rejection
  Then no signage request is sent for that EVSE
  And the booking is reallocated as in JS-018, or handled as a full site (JS-019) if no compatible EVSE is free

## Notes

- Depends on: A-012 (site staff do physical station holds), Q-009, and A-048 with Q-059 (Gowanus site staff receive
  station-hold and clear requests and acknowledge them through a site-scoped login or an SMS reply; Q-041 and A-046
  cover JFK). S1 holds under A-048 (constitution R7). "Within the set time" is a configured value; its default is a
  design detail for Step 3.3.
- S4 applies REQ-020 (JS-018), which forbids a station-hold request for an EVSE a walk-up is using; REQ-155 alone would
  send one. Confirmed in the Step 3.1 red-team pass: the specific rules (REQ-020, and REQ-021 for an EVSE occupied at
  station-hold time) take precedence over the general fallback (REQ-155).
- If the charger accepts the reservation after the platform has already fallen back to a signage request (a late
  answer), whether the signage request is withdrawn is a design detail for Step 3.3.
