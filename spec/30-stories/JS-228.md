# JS-228 · Keyword replies understood in English, Spanish and Bengali

When I cannot open the booking page, I want to answer a message about my booking with one short word in English,
Spanish or Bengali to cancel, say I am running late, accept or decline an alternative, or ask for help, so I can act
on the booking with the least effort instead of letting the slot lapse.

## Acceptance criteria

Scenario: S1 (happy path) Cancel in Spanish
  Given a driver whose language is Spanish received a reminder about a booking
  When the driver replies with the Spanish cancel keyword
  Then that booking is cancelled
  And the driver gets a reply in Spanish naming the booking cancelled

Scenario: S2 (happy path) Running late in Bengali
  Given a driver whose language is Bengali received a reminder about a booking
  When the driver replies with the Bengali running-late keyword
  Then the booking records that the driver is running late
  And the driver gets a reply in Bengali

Scenario: S3 (happy path) Accept an alternative
  Given a driver was offered an alternative slot by message
  When the driver replies with the accept keyword in English
  Then the alternative is accepted
  And the driver gets a reply naming the booked slot

Scenario: S4 (happy path) Decline an alternative
  Given a driver was offered an alternative slot by message
  When the driver replies with the decline keyword in Spanish
  Then nothing is booked from the offer
  And the driver gets a reply confirming the decline

Scenario: S5 (failure) A word the platform does not recognise
  Given a driver received a message about a booking
  When the driver replies with a word that is not a keyword in any of the three languages
  Then the booking is unchanged
  And the message goes to ops as not understood (REQ-222)

Scenario: S6 (failure) A keyword from a number that may not change the booking
  Given a booking whose booker and charging driver are known
  When a cancel keyword about it arrives from another number
  Then the booking is unchanged (REQ-242)

Scenario: S7 (edge case) A keyword in a language other than the driver's own
  Given a driver whose language is Bengali
  When the driver replies with the English cancel keyword
  Then the booking is cancelled
  And the reply is in Bengali

Scenario: S8 (edge case) Letter case and surrounding spaces
  Given a driver received a reminder
  When the driver replies " Cancel " or "CANCEL"
  Then it is understood as the cancel keyword

Scenario Outline: S9 (happy path) Every keyword in every language
  Given a driver received a message about a booking to which the <keyword> keyword applies
  When the driver replies with the <keyword> keyword in <language>
  Then the platform records the reply as the <keyword> command for that booking
  And the reply is not listed for ops as a message the platform cannot understand

  Examples:
    | keyword       | language |
    | cancel        | English  |
    | cancel        | Spanish  |
    | cancel        | Bengali  |
    | running late  | English  |
    | running late  | Spanish  |
    | running late  | Bengali  |
    | accept        | English  |
    | accept        | Spanish  |
    | accept        | Bengali  |
    | decline       | English  |
    | decline       | Spanish  |
    | decline       | Bengali  |
    | help          | English  |
    | help          | Spanish  |
    | help          | Bengali  |

## Notes

- The keyword reply applies to the booking the message was about (REQ-041, FT-01.2). One-tap cancel and running late
  in the page are N23 and REQ-039.
- The keywords in each language are set with Amperlane's bilingual ops team (A-042). The keyword catalogue, including
  whether Bengali keywords are recognised in Bengali script, Latin transliteration or both, is a design detail for
  Step 3.3.
- "Help" replies: what the platform answers is not stated beyond REQ-222 (unclear messages to ops); REQ-221 (how to
  reach ops) is I. What a recognised help keyword does (a reply in the driver's language, a listing for ops, or both)
  is a design detail for Step 3.3; S9 checks only that it is recognised.
- Red team: S1 – S4 each test one keyword in one language, so a build covering only those pairs passed them; S9 checks
  all five keywords in all three languages.
