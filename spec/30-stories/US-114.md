As Amperlane ops, I want a disputed no-show's whole history in order on one screen, with the driver's location
evidence shown only while the dispute is open, so that I decide disputes on evidence without exposing drivers'
location at any other time.

## Acceptance criteria

Scenario: S1 · happy path · All the evidence on one screen
  Given an open dispute on a no-show
  When an ops user opens the dispute
  Then one screen shows the booking's history in time order: each state with its actor and reason code, the station-hold attempts and their responses, the EVSE status at each of those times, the arrival evidence, the messages sent to the driver and the session record

Scenario: S2 · happy path · Location evidence inside an open dispute
  Given the driver had opted in and an arrival event derived from location exists for the booking
  When an ops user opens the open dispute
  Then the location evidence is shown
  And the view is recorded in the audit trail with the ops user and the time

Scenario: S3 · failure · No location evidence outside an open dispute
  Given a booking with location evidence and no open dispute
  When an ops user views the booking in the ops console
  Then no location evidence is shown

Scenario: S4 · failure · A closed dispute hides the location again
  Given the dispute on a booking with location evidence was decided and closed
  When an ops user views the booking
  Then no location evidence is shown

Scenario: S5 · failure · No session record was received
  Given no session record was received for the disputed booking
  When an ops user opens the dispute
  Then the screen states that no session record exists for the booking

Scenario: S6 · edge case · Stale status at the time is shown as stale
  Given the EVSE status the platform held at a station-hold attempt was older than 60 seconds at a connected site (constitution N2)
  When an ops user opens the dispute
  Then that status is shown as stale, with its age at the time

## Notes

- A-024: with location off by default, most disputes have no location evidence; QR scans and the attendant are the
  usual arrival evidence. A-047: evidence is kept at least until the dispute window closes.
- Status at a past moment comes from REQ-164 (FT-05.2); staleness follows constitution N2; view logging follows
  REQ-263 (FT-13.2). Session records are unconfirmed (U-6; Q-009, Q-012).
- No K or Y requirement collects location yet (REQ-173, REQ-175 are I), so S2 – S4 apply once one is admitted.
