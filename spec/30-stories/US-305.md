# US-305 · Import a fleet's vehicles and driver numbers from one file

As a fleet manager, I want to import all the fleet's vehicles and driver numbers from one file, with every invalid row
listed, so that a fleet of hundreds of vehicles gets onto the platform in one go instead of being typed in one vehicle
at a time.

## Acceptance criteria

Scenario: S1 (happy path) A valid file is imported
  Given a file listing the fleet's vehicles, each with its plate, native connector, allowed adapters and maximum DC charging power, and its drivers' mobile numbers
  When the fleet manager imports it in the fleet portal
  Then every row is registered to the fleet
  And the fleet manager sees how many vehicles and driver numbers were registered

Scenario: S2 (happy path) Ops imports for a fleet without portal users
  Given a fleet that ops onboards on its behalf
  When Amperlane ops imports the same kind of file for that fleet
  Then its rows are registered to that fleet

Scenario: S3 (failure) Invalid rows are listed with their reasons
  Given a file in which some rows lack a connector or a maximum power, or carry an invalid mobile number
  When it is imported
  Then each invalid row is listed with its row number and the reason
  And the valid rows are registered and the invalid rows are not

Scenario: S4 (failure) An unreadable file is rejected whole
  When the fleet manager imports a file that is not in the expected format
  Then nothing is registered
  And the fleet manager is told the file could not be read

Scenario: S5 (failure) Import into another fleet is refused
  When a fleet manager imports a file for a fleet that is not theirs
  Then the import is refused and nothing is registered

Scenario: S6 (edge case) The corrected file is imported again
  Given a file was imported with some invalid rows
  When the fleet manager fixes those rows and imports the whole file again
  Then the rows registered by the first import are not registered twice
  And the fixed rows are registered

## Notes

- S3 and S6 read REQ-207 as: valid rows are registered, invalid rows are listed and skipped, and a re-import does not
  duplicate rows. REQ-207 does not say whether an import with errors is all-or-nothing; that is a design detail for
  Step 3.3.
- "Hundreds of vehicles": Borough Green leases about 420 EVs (CTX-073). The file format is decided in Step 3.3.
- Depends on A-023, Q-028. Every external file is validated against a schema at the edge (constitution SC7).
