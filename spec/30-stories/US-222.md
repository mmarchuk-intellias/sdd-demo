# US-222 · Text commands count only from the booker or the charging driver

As a charging driver, I want a text that changes my booking to count only when it comes from my registered number or
my booker's, so that nobody else can cancel or change my booking by text.

## Acceptance criteria

Scenario: S1 (happy path) The charging driver cancels by text
  Given a booking whose charging driver is a registered number
  When a cancel command about that booking arrives by SMS from that number
  Then the booking is cancelled

Scenario: S2 (happy path) The booker changes the booking by text
  Given a booking whose booker and charging driver are different registered numbers
  When a running-late command about that booking arrives from the booker's number
  Then the command is applied to the booking

Scenario: S3 (failure) Another driver of the same fleet
  Given a booking of the Borough Green fleet
  When a cancel command about that booking arrives from another Borough Green driver's number
  Then the booking is unchanged
  And neither the booker nor the charging driver gets a message that the booking changed

Scenario: S4 (failure) An unregistered number
  Given a booking
  When a cancel command about it arrives from a number that is not registered to any fleet
  Then the booking is unchanged

Scenario: S5 (edge case) The same rule on WhatsApp
  Given a booking whose charging driver uses WhatsApp
  When a cancel command about it arrives on WhatsApp from the charging driver's number
  Then the booking is cancelled
  And the same command from any other number on WhatsApp leaves the booking unchanged

Scenario: S6 (edge case) A booker removed from the fleet after making the booking
  Given a Borough Green driver booked a slot for another Borough Green driver as charging driver
  And the fleet then removed the booker from Borough Green
  When a running-late command about that booking arrives by SMS from the removed booker's number
  Then the command is not applied to the booking
  And no running-late report is added to it

## Notes

- Depends on A-006 and A-023 (booker-only numbers). Which booking a keyword reply applies to is REQ-041 (FT-01.2):
  the booking the message was about.
- S6 follows A-052 (working assumption for Q-045): from the moment of removal, a removed number can no longer change
  the fleet's bookings, as booker or charging driver, on any channel. The number is then no longer a registered number
  of the booking's fleet, so REQ-242 refuses its commands. The red team had removed an earlier version of this
  scenario while Q-045 had no working assumption; S6 holds whether the removed driver's bookings stand or are
  cancelled.
- WhatsApp (S5): Q-034, A-008.
