# US-227 · Every message and driver PWA screen in the driver's language

As a driver who is more comfortable in Spanish or Bengali, I want every message and every driver PWA screen in my
language, so that I understand my bookings without calling a bilingual ops person.

## Acceptance criteria

Scenario: S1 (happy path) A Bengali-speaking driver
  Given a driver whose language is set to Bengali
  And the driver's phone and browser are set to English
  When the driver receives booking messages and opens the driver PWA
  Then every message and every screen the driver sees is in Bengali

Scenario: S2 (happy path) Who can set the language
  Given a driver with a language set
  When the fleet, ops or the driver sets the driver's language to Spanish
  Then messages and screens from then on are in Spanish

Scenario: S3 (failure) No language is set
  Given a driver with no language set
  And the driver's phone and browser are set to Spanish
  When the driver receives a message or opens the driver PWA
  Then it is in English

Scenario: S4 (edge case) The language changes after a booking was made
  Given a driver received a confirmation in English
  When the driver's language is changed to Bengali before the reminder
  Then the reminder is in Bengali
  And the confirmation already sent is not sent again

Scenario: S5 (edge case) Booker and charging driver have different languages
  Given a booker whose language is Spanish books for a charging driver whose language is Bengali
  When each receives a message about the booking
  Then the booker's message is in Spanish and the charging driver's is in Bengali

Scenario: S6 (edge case) Only the three languages are offered
  Given a fleet manager, ops or a driver sets a driver's language
  When the language choices are shown
  Then they are English, Spanish and Bengali

Scenario: S7 (failure) A language the platform does not offer
  Given a driver whose language is set to Spanish
  When the fleet, ops or a file import tries to set the driver's language to one other than English, Spanish or
    Bengali
  Then the change is refused with the reason
  And the driver's language stays Spanish

## Notes

- Baseline: constitution N22 (CI fails when a message key lacks EN, ES or BN). A-042: other interfaces are English
  only; a native speaker from ops reviews new Spanish and Bengali texts before each release.
- Which setting wins when the fleet, ops and the driver set different languages (for example the latest one) is a
  design detail for Step 3.3.
- Red team: S1 and S3 fix the phone's language to differ from the driver's, so a PWA that follows the browser
  language instead of the stored one fails them (REQ-199: English only when no language is set). S7 follows
  constitution SC7 (input validated at the edge).
- WhatsApp messages started outside the 24-hour window use templates in the driver's language (REQ-249, US-215).
