# US-230 · Consent texts and fee notices in three languages, with the accepted version kept

As a driver, I want the consent texts and fee notices I am asked to accept to be in my own language, and the exact
version I accepted to be kept, so that I know what I agreed to and am never held to wording I did not see.

## Acceptance criteria

Scenario: S1 (happy path) A driver accepts a consent text in Spanish
  Given a driver whose language is Spanish is shown a consent text
  When the driver accepts it
  Then the text shown was the Spanish version
  And the platform stores which version and language the driver accepted, with the time

Scenario: S2 (failure) The driver does not accept
  Given a driver is shown the consent text for location
  When the driver closes it without accepting
  Then no acceptance is stored
  And the purpose it covers stays off for the driver (location stays off, A-024)

Scenario: S3 (failure) A version is missing a language
  Given a new version of a consent text exists in English and Spanish but not in Bengali
  When the platform would show consent texts to drivers
  Then that version is not shown to any driver
  And drivers keep seeing the last version that exists in all three languages

Scenario: S4 (edge case) The driver changes language later
  Given a driver accepted the Spanish version of a consent text
  When the driver's language is changed to Bengali
  Then the stored acceptance still shows the Spanish version, with its time

Scenario: S5 (edge case) A new version is published
  Given a driver accepted version 1 of a fee notice
  When version 2 of the fee notice is published in all three languages
  Then the stored acceptance of version 1 is unchanged

## Notes

- Counsel approves the wording (A-024; Q-016 for the consent basis). Fee notice content depends on who pays a no-show
  fee (Q-002, undecided); this story does not assume the payer.
- Whether a driver must accept a new version before the purpose it covers continues is Q-057, a client decision; S5
  holds under any answer, since it fixes only that the stored acceptance of the earlier version is unchanged.
- "Consent texts" cover location consent (A-024) and, if captured in the platform, agreement to booking messages
  (REQ-248, US-229). Retention of acceptances follows A-025.
