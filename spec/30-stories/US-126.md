As Amperlane ops, I want to find a driver's bookings, messages and fees with one search by mobile number, plate or
booking code, and to message the driver on their channel from the same place, so that I can answer a driver's call or
text without switching tools.

## Acceptance criteria

Scenario: S1 · happy path · Search by mobile number
  Given a registered driver with bookings, messages and fees
  When an ops user searches for the driver's mobile number
  Then the result shows the driver's bookings, messages and fees

Scenario: S2 · happy path · Search by booking code or plate
  Given a booking with a booking code, made for a vehicle with a plate
  When an ops user searches for the booking code, or for the plate
  Then the result shows that booking with its driver, messages and fees

Scenario: S3 · happy path · Send a templated message
  Given an ops user has found a driver's booking
  When the ops user sends a templated message to the driver
  Then the driver gets it on the driver's channel, in the driver's language
  And the message is recorded against the booking with the ops user and the time

Scenario: S4 · failure · No match
  Given no driver, vehicle or booking matches a search
  When an ops user runs the search
  Then the result states that nothing matches

Scenario: S5 · failure · The driver has stopped messages on that channel
  Given the driver replied STOP on the channel the message would use
  When an ops user sends the driver a message
  Then the message is not sent on that channel
  And the ops user is told why

Scenario: S6 · edge case · A plate shared by several drivers
  Given a vehicle whose bookings were made for different drivers on different shifts
  When an ops user searches for its plate
  Then the result shows each of those bookings with its own driver

Scenario: S7 · edge case · A free-text message
  Given an ops user has found a driver's booking
  When the ops user sends a free-text message
  Then the driver gets the text as written, on the driver's channel
  And the message is recorded against the booking

## Notes

- Ops take dozens of driver calls a day (CTX-045) and texted each driver by hand in the Gowanus fault (CTX-047).
- S5 follows REQ-248 (FT-06.5); the driver's language follows REQ-199. The full message history with delivery status
  is REQ-196 (I) and is not assumed. Views of a driver's personal data are audit-logged (REQ-263).
- Channels: SMS, and WhatsApp once set up (U-10; Q-034, A-008).
