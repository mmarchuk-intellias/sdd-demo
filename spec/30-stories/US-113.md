As a fleet manager, I want to dispute a no-show on one of my fleet's bookings and get Amperlane's decision with its
reason, so that my fleet does not pay a no-show fee when the evidence shows the driver was not at fault.

## Acceptance criteria

Scenario: S1 · happy path · A fleet manager disputes and ops reverse the fee
  Given a no-show with a fee line on a booking of the fleet, inside the dispute window (A-047: 30 days after the booking)
  When the fleet manager raises a dispute on the no-show
  Then the dispute appears as an open dispute in the ops exception queue
  When an ops user decides to reverse the fee line, with a reason code
  Then the fee line is reversed without changing any energy line
  And the fleet manager receives the decision and its reason code

Scenario: S2 · happy path · A driver disputes and ops keep the fee
  Given a driver's no-show is inside the dispute window
  When the driver raises a dispute on it
  And an ops user decides to keep the fee line, with a reason code
  Then the fee line stays as it was
  And the driver receives the decision and its reason in the driver's language

Scenario: S3 · failure · A dispute after the window is refused
  Given a no-show whose dispute window has closed
  When the fleet manager tries to raise a dispute on it
  Then no dispute is opened
  And the fleet manager is told the dispute window has closed

Scenario: S4 · failure · A fleet cannot dispute another fleet's booking
  Given a no-show on a booking of another fleet
  When the fleet manager tries to raise a dispute on it
  Then no dispute is opened

Scenario: S5 · failure · A decision without a reason code is refused
  Given an open dispute
  When an ops user tries to record a decision without a reason code
  Then the decision is refused
  And the dispute stays open

Scenario: S6 · edge case · The fee was already invoiced
  Given the disputed fee line is on an invoice that was already issued
  When an ops user decides to reverse it, with a reason code
  Then a credit line appears on the fleet's next invoice
  And the issued invoice is unchanged

## Notes

- Q-043 is covered by A-047 (a fleet or a driver, within 30 days of the booking). Q-002: the payer is undecided; the
  dispute flow holds in every option.
- The reversal follows REQ-212 and REQ-213 (FT-10.x); the evidence screen is US-114; the queue is US-124; S4 follows
  REQ-258.
- How a driver, or a small fleet that does not use the fleet portal (REQ-243), raises a dispute is a design detail for
  Step 3.3.
