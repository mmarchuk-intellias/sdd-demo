# US-302 · Fleet manager registers the fleet's drivers' mobile numbers

As a fleet manager, I want to register my drivers' mobile numbers in the fleet portal, so that my drivers can book
from the phone they already use, with no app or account, and only people the fleet has registered can book its
vehicles.

## Acceptance criteria

Scenario: S1 (happy path) A fleet manager registers a driver
  Given a fleet manager signed in to the fleet portal
  When the fleet manager registers a driver's mobile number
  Then the number is listed among the fleet's drivers
  And from that moment a booking from that number for one of the fleet's vehicles is accepted under the usual capacity and compatibility rules

Scenario: S2 (failure) An unregistered number cannot book for the fleet
  Given a mobile number that is not registered to the fleet
  When that number tries to book one of the fleet's vehicles by message or in the driver PWA
  Then no booking is made for the fleet

Scenario: S3 (failure) An invalid or repeated number is refused
  Given the fleet already has a driver with a given mobile number
  When the fleet manager registers that number again, or a number that is not a valid phone number
  Then no second entry is created and the invalid number is not registered
  And the fleet manager is told which number was refused and why

Scenario: S4 (failure) A fleet manager cannot register drivers for another fleet
  When a fleet manager tries to register a driver for a fleet that is not theirs
  Then the request is refused and nothing is registered

Scenario: S5 (edge case) The number already drives for another fleet
  Given a mobile number registered to another fleet
  When the fleet manager registers it
  Then it is registered to this fleet as well
  And the fleet manager sees nothing of the other fleet: not its name, its vehicles nor its bookings with that number

## Notes

- Depends on A-023, Q-028 and A-016.
- Registration is not messaging consent (REQ-248, EP-06). Removing a driver is REQ-202 (Q-045), booker-only numbers
  REQ-201; both belong to other features.
- S2 restates the booking rule of REQ-009 and A-023 from the registration side. S4 and S5 rely on REQ-258 (EP-13).
- Other ways to register: ops on the fleet's behalf (US-301), file import (US-305).
