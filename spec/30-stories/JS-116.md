When an EVSE with bookings faults, whether its CSMS reports it or the LIC attendant marks it, I want to have it taken
out of new allocations and its bookings sent to fault rebooking within a set time, so I can act on the fault before a
driver arrives at it instead of learning about it from a driver's text.

## Acceptance criteria

Scenario: S1 · happy path · A fault status by webhook
  Given EVSE A at a connected site has bookings later that day
  When the CSMS reports EVSE A as faulted by webhook
  Then within the set time EVSE A is excluded from new allocations
  And fault rebooking of its bookings starts (JS-119)
  And the ops console shows EVSE A as faulted with the time the status was observed

Scenario: S2 · happy path · A fault set by the LIC attendant
  Given EVSE C at LIC has bookings later that day
  When the attendant sets EVSE C to faulted in the attendant view
  Then within the set time EVSE C is excluded from new allocations
  And the same fault rebooking starts as for a fault reported by a CSMS

Scenario: S3 · failure · The webhook is lost and the poll finds the fault
  Given the CSMS's fault webhook for EVSE A never arrived
  When the next poll returns EVSE A as faulted
  Then within the set time of the poll EVSE A is excluded from new allocations
  And fault rebooking of its bookings starts

Scenario: S4 · failure · A duplicated fault status starts nothing twice
  Given the platform already acted on a fault status for EVSE A
  When the same fault status arrives again
  Then fault rebooking for EVSE A is not started a second time

Scenario: S5 · edge case · An out-of-order fault status
  Given the platform holds an "available" status for EVSE A that was observed after a "faulted" status still in transit
  When the older "faulted" status arrives
  Then EVSE A stays in the pool
  And no fault rebooking starts

Scenario: S6 · edge case · A fault on an EVSE with no bookings
  Given EVSE A has no bookings later that day
  When the CSMS reports EVSE A as faulted
  Then EVSE A is excluded from new allocations
  And no driver gets a message about it
