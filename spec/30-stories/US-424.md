# US-424 · One team from Phase 0 and a signed integration-layer handover

As the Amperlane engineer who will own the integration layer (Priya Nair), I want to work in the same repositories and
rituals as the Intellias team from Phase 0, and to sign the integration-layer handover checklist only when I can run
each integration myself, so that Amperlane's two engineers can run and change the platform after handover with no
black box.

## Acceptance criteria

Scenario: S1 (happy path) Amperlane engineers in the team from Phase 0
  Given Phase 0 has started
  When the team plans, builds and reviews its work
  Then Amperlane's engineers have the same access to the repositories and task tracker as the Intellias engineers,
    including the right to open and review changes
  And they take part in the same team rituals as the Intellias engineers
  And their changes go through the same review as everyone else's

Scenario: S2 (happy path) Priya Nair signs the handover checklist
  Given the integration-layer handover checklist lists every integration the platform runs in production at handover
  When Priya Nair has demonstrated each item herself, without help from Intellias staff
  Then she signs the checklist
  And the signed checklist is kept with the handover record

Scenario: S3 (failure) An item she cannot yet demonstrate
  Given a checklist item for one integration that Priya Nair cannot yet demonstrate
  When the handover is reviewed
  Then that item is not signed
  And the handover of that integration stays open with the item named

Scenario: S4 (failure) Work done where Amperlane engineers cannot see it
  Given a change to the platform made in a repository or tracker that Amperlane's engineers cannot access
  When the change is offered as done
  Then it is not accepted as done until it is in Amperlane's repositories and visible to Amperlane's engineers

Scenario: S5 (edge case) An integration added after the checklist was drafted
  Given a new integration is added to the platform after the checklist was drafted, for example the CSMS of a new site
  When the handover is reviewed
  Then that integration is on the checklist and must be signed like the others
