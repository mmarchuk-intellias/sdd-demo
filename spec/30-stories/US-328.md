# US-328 · Series A data-room report on demand, traceable to booking ids

As Amperlane's CEO, I want the Series A data-room report produced on demand for any range of months since October 2025,
with every figure traceable to its booking ids, so that investors can check our pilot and platform figures down to the
bookings behind them.

## Acceptance criteria

Scenario: S1 (happy path) A report for a range of months
  Given pilot and platform bookings from October 2025 onwards
  When the CEO asks for the data-room report for a range of months
  Then the report gives each of its figures per month, computed under the configured completed-booking definition
  And each figure states the definition it was computed under
  And each figure can be expanded to the list of booking ids it was computed from

Scenario: S2 (happy path) With or without pilot data
  Given a range that includes pilot months
  When the CEO produces the report
  Then pilot data is marked as such
  And every figure can be shown with or without it

Scenario: S3 (failure) A range that starts before October 2025
  When the CEO asks for a range that starts before October 2025
  Then the report covers only the months from October 2025 and says that earlier months have no data

Scenario: S4 (failure) Fleet and station operator users cannot produce it
  When a fleet manager or a station operator asks for the data-room report
  Then the request is refused

Scenario: S5 (edge case) The same range produced twice
  Given no new evidence was recorded in between
  When the report for the same range is produced twice
  Then both have the same figures and the same booking ids behind each figure

## Notes

- Depends on A-026 (pilot history migrated and cleaned), Q-017 (definition) and CF-018.
- The figures the data-room report must contain are not defined: Q-020 asks what the data room needs, and A-026
  covers the migrated history. The tests use completed bookings and no-shows per month as examples.
- Migrated records from before February 2026 carry a data-quality flag (REQ-230, EP-12); whether the report shows it is
  not stated.
- Which Amperlane roles may produce the report is not stated; S4 only excludes other organisations (REQ-258).
