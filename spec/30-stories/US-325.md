# US-325 · Finance views for invoices, reconciliation and disputes, with no operational rights

As Amperlane finance, I want my own views of fleet invoices, reconciliation against session records and disputes,
without the power to change bookings, capacity rules or fleet policies, so that I can run month-end checks myself while
operational settings stay with ops, station operators and fleets.

## Acceptance criteria

Scenario: S1 (happy path) Finance opens its views
  Given a user with the finance role
  When the user signs in
  Then they can open the fleet invoices with their payment status
  And the reconciliation queue with each booking and session record in it
  And the disputes with their outcome and the fee line each one affected

Scenario: S2 (failure) Finance cannot change a booking
  Given a finance user viewing a booking from a dispute
  When the user tries to confirm, cancel, rebook or override the booking, in the console or directly through the API
  Then the request is refused and the booking is unchanged

Scenario: S3 (failure) Finance cannot change capacity rules or fleet policies
  When a finance user tries to change a site's capacity rule or a fleet's policy, in any view or directly through the
    API
  Then the request is refused and nothing changes

Scenario: S4 (edge case) Finance sees every fleet and every site
  Given fleet invoices of several fleets, and reconciliation items at sites of several station operators
  When a finance user opens the fleet invoices and the reconciliation queue
  Then the invoices of every fleet and the reconciliation items of every site are listed
  And no fleet manager or station operator user can open these views
