# US-009 · Fleet manager books for a named driver

As a fleet manager, I want to book a slot for a named driver of my fleet, so that drivers who do not book for
themselves still get a guaranteed charge when the fleet needs the vehicle charged.

## Acceptance criteria

Scenario: S1 (happy path) Book in the fleet portal for a named driver
  Given a fleet manager is signed in to the fleet portal
  When the fleet manager books an open slot for a vehicle of the fleet and names a driver of the fleet
  Then the booking is confirmed with the named driver's mobile number as charging driver
  And the booking records the fleet manager as its booker
  And the booking's history names the fleet manager as the person who made it

Scenario: S2 (failure) The named driver is not a driver of the fleet
  Given a mobile number that is not registered to the fleet
  When the fleet manager names it as the driver of a booking
  Then the booking is refused

Scenario: S3 (failure) A fleet manager cannot book another fleet's vehicle
  Given a fleet manager of Borough Green Fleet LLC
  When the fleet manager tries to book a vehicle of Five Boroughs EV Cab Co.
  Then the booking is refused

Scenario: S4 (failure) The same capacity and compatibility rules apply
  Given the slot the fleet manager wants is at the cap of the site's capacity rule, or has no EVSE the vehicle can use
  When the fleet manager tries to book it
  Then the booking is refused as it would be for a driver

Scenario: S5 (edge) A driver of two fleets is booked by one of them
  Given a driver is registered to both Borough Green Fleet LLC and another fleet
  When the Borough Green fleet manager books a Borough Green vehicle for that driver
  Then the booking is confirmed for the Borough Green vehicle with that driver as charging driver
