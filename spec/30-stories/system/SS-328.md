# SS-328 · Driver PWA screens in the driver's language: English, Spanish or Bengali

As the Driver PWA, I need every screen in the language stored for the driver, so that a Spanish- or Bengali-speaking
driver understands every screen whatever the phone is set to.

## Acceptance criteria (EARS)
1. [Ubiquitous] The Driver PWA shall render every screen in the language stored for the session's driver (SS-303),
   whatever the language of the phone or browser.
2. [State] While no language is stored for the driver, the Driver PWA shall render every screen in English.
3. [Ubiquitous] The Driver PWA shall contain no screen text that lacks an English, a Spanish or a Bengali version
   (constitution N22).
4. [Event] When the driver chooses a language in the Driver PWA, from English, Spanish and Bengali only, the Driver PWA
   shall have it stored (SS-303) and render every screen in it from then on.
5. [Unwanted] If a session with limited scope asks to change the language, then the Driver PWA shall ask for the
   one-time code first (SS-321).

## Notes
- PWA languages come from SRC-D2#13 (Intellias) and are agreed for driver messages (SRC-C2@00:50:56); A-042 sets the
  stored-language rule and the native-speaker review.
- Who may set the language and which setting wins: SS-303 (#34). Messages: SS-302.
