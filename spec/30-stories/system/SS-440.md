# SS-440 · Finance role: read-only, refused on booking, capacity-rule and fleet-policy commands

As the Identity & access component, I need the finance role to carry read access to the finance views and no
permission for any command that changes a booking, a capacity rule or a fleet policy, checked on every API call, so
that finance can check a month end without being able to change operations, however they reach the platform.

## Acceptance criteria (EARS)
1. [Ubiquitous] The Identity & access component shall define the finance role with read access to the finance views
   (SS-411) and the fleet position (SS-403), and with no permission for any command of the booking, inventory or fleet
   modules.
2. [Unwanted] If a finance user sends a command that confirms, cancels, rebooks or overrides a booking, from the ops
   console or directly to the API, then the Identity & access component shall refuse it with the code FORBIDDEN before
   it reaches the booking engine, so that the booking stays unchanged.
3. [Unwanted] If a finance user sends a command that changes a site's capacity rule or a fleet's policy, from any view
   or directly to the API, then the Identity & access component shall refuse it with the code FORBIDDEN, so that
   nothing changes.
