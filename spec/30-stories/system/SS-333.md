# SS-333 · Configuration change audit with before and after values

As the Audit & data protection component, I need every change to capacity rules, site parameters, fleet policies,
partner terms, user roles and per-EVSE settings recorded with its actor, time and before and after values, so that a
disagreement about what applied at a given time is settled from the record.

## Acceptance criteria (EARS)
1. [Event] When a capacity rule, a site's bookable hours, a per-site booking parameter, a partner term, a fleet policy,
   a user role, a per-EVSE setting or a driver's language is saved, the Audit & data protection component shall append
   an entry with the signed-in person who saved it, the item, each changed field with its value before and after, and
   the time.
2. [Ubiquitous] The Audit & data protection component shall record the signed-in person as the actor, also when an ops
   user changes an item on an organisation's behalf.
3. [Event] When a user asks for the value of a configured item at a past instant, the Audit & data protection component
   shall return the value in force at that instant, derived from these entries.
4. [Unwanted] If a configuration change cannot be recorded, then the Audit & data protection component shall refuse
   it, so the change is not saved.
5. [Unwanted] If anyone tries to edit or delete a change entry, then the Audit & data protection component shall refuse
   it and leave the entry unchanged.
