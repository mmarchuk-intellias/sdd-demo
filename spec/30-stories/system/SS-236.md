# SS-236 · Station portal capacity-rule saves: one idempotency key per form, repeated on every resend

As the Partner portals component, I need the station portal to send one idempotency key with each capacity-rule change
and the same key again whenever that change is sent again from the same form, so that a save repeated after a lost
response changes the site's capacity rules once.

## Acceptance criteria (EARS)
1. [Ubiquitous] The station portal shall send an idempotency key with every capacity-rule change it submits.
2. [Unwanted] If a capacity-rule change is sent again from the same form, by the user or by a retry after no response
   arrived, then the station portal shall send the same idempotency key as with the first save.
3. [Event] When a user opens a new capacity-rule form, the station portal shall use a new idempotency key for the
   change submitted from it.
