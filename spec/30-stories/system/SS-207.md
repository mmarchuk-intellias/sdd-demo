# SS-207 · Attendant status reports as the status source for the attendant's site

As the EVSE status service, I need to take the attendant's free, occupied and faulted settings as the live status of
the attendant's site, faults included, so that a site without a charger API has real status and the same fault
handling as a connected site.

## Acceptance criteria (EARS)
1. [Event] When the attendant signed in for a site sets an EVSE of that site to free, occupied or faulted, the EVSE
   status service shall apply it as the EVSE's status (available, occupied or faulted), with the time of the
   attendant's update as observed-at and the attendant view as source.
2. [Unwanted] If an attendant sets the status of an EVSE at a site other than the one the attendant is signed in for,
   then the EVSE status service shall refuse the change and leave the EVSE's status unchanged.
3. [Event] When the attendant sets an EVSE to faulted, the EVSE status service shall emit the same status-changed event
   to faulted as for a CSMS fault, so that fault intake (SS-208) and fault rebooking run as at a connected site.
4. [Unwanted] If the attendant sets an EVSE to the status it already has, then the EVSE status service shall record
   the attendant's update time as the new observed-at time and emit no status-changed event.

## Notes
- Covers US-031 S1, S2 and S4, JS-116 S2 (with SS-208), and the source side of JS-118 S5 (SS-209 clause 6). US-031 S3
  (old attendant status) is SS-202 clause 3; US-031 S5 (reallocation at the pre-arrival check) is SS-104.
- Clause 4 lets the attendant confirm a status without changing it; "last updated by attendant at" then shows that
  time (REQ-160).
- The attendant's "occupied" on an allocated EVSE is the session-start evidence at LIC (A-051); arrival and
  charge-not-started read it from the status-changed event (SS-125, SS-107, SS-225).
- The attendant's site-scoped login is SS-324. R7: the attendant's use of the view is unconfirmed (integrations.md
  U-13): A-021, Q-010, Q-049, A-054. If the attendant does not report, LIC has no live status and falls back to ops
  calls (A-054).
