# SS-041 · Bulk import of vehicles and driver numbers with per-row errors

As the Fleet & vehicles module, I need to import a fleet's vehicles and driver numbers from one file, register the
valid rows and list every invalid row with its reason, so that a fleet of hundreds of vehicles gets onto the platform in
one go and a corrected file can be imported again safely.

## Acceptance criteria (EARS)
1. [Event] When a fleet manager in the fleet portal, or ops for a fleet, import a file in the published import format,
   the Fleet & vehicles module shall check every row against the format and the rules of SS-037 and SS-038, register
   every valid row to that fleet and report how many vehicles and driver numbers were registered.
2. [Unwanted] If some rows of the file are invalid, then the Fleet & vehicles module shall list each of them with its
   row number and the reason, register the valid rows and register none of the invalid ones.
3. [Unwanted] If the file is not in the published import format, then the Fleet & vehicles module shall reject it whole,
   register nothing and say that the file could not be read.
4. [Event] When a file is imported that contains rows already registered to the fleet, the Fleet & vehicles module shall
   register those rows no second time, report them as already registered, and register the other valid rows.

## Notes
- Covers US-305 S1 – S4 and S6. S5 (another fleet) is SS-323.
- Settles bucket-5 #38: valid rows are registered, each invalid row is listed with its row number and reason, and a
  re-import of the corrected file registers no row twice (REQ-207).
- Proposed import format (US-305 note): one CSV file, UTF-8, with a header row and a record_type column (vehicle or
  driver); vehicle rows carry plate, native_connector, allowed_adapters, max_dc_kw; driver rows carry mobile_number.
  A row is "already registered" when its plate is an active vehicle of the fleet, or its number a driver of the fleet;
  a re-import does not change an existing vehicle's profile (edits go through SS-038).
- Borough Green leases about 420 EVs (CTX-073). Every external file is validated against a schema at the edge
  (constitution SC7).
