# SS-112 · Ops one-action rebooking of all bookings of an EVSE, marking it faulted

As the Allocation & rebooking component, I need to let ops take an EVSE out as faulted and rebook all its bookings in
one action, so that ops can protect the day's drivers when they learn of a fault before the platform does.

## Acceptance criteria (EARS)
1. [Event] When an ops user rebooks all bookings of an EVSE in one action with a reason code from the catalogue, the
   Allocation & rebooking component shall have the EVSE recorded as faulted by ops, so it gets no new allocations until
   it returns to service (SS-208, SS-209), handle its bookings as in SS-108 clauses 1 – 4 with the reason code
   'moved — charger fault' and the ops user as actor on each rebooking, and record and emit their outcomes as in
   SS-108 clauses 8 and 10.
2. [Unwanted] If fault rebooking for that EVSE has already started, then the Allocation & rebooking component shall
   rebook no booking a second time and handle only the bookings still on the EVSE.
3. [Event] When the action is taken on an EVSE whose interrupted fault rebooking left bookings on it with ops
   exceptions, the Allocation & rebooking component shall rebook or hand to unplaced handling exactly those bookings,
   whose earlier exceptions the fault-rebooking saga then reports resolved (SS-036 clause 5).
4. [Unwanted] If the action has no reason code from the catalogue, then the Allocation & rebooking component shall
   refuse it and change no booking and no EVSE status.

## Notes
- Settles bucket-5 item 22: the single action marks the EVSE faulted (out of new allocations, as REQ-047) and rebooks
  with 'moved — charger fault'; the EVSE returns under REQ-194 (SS-209).
- A-017 and CF-022: automatic rebooking is the main path; this action is the fallback when drivers or the station
  operator report a fault first (CTX-048, JS-117).
- Unplaced bookings follow SS-109 and SS-110.
- P3.4 (2026-10-28): clause 1 now records outcomes (SS-108 clauses 8 and 10), so an ops one-action fault reaches the
  fault summary, the station portal and reporting like an automatic one. Clause 3 no longer marks the earlier
  exceptions resolved itself: SS-036 clause 5 (their raiser) does, which removes a double resolution of one exception
  by two SS on the same trigger.
