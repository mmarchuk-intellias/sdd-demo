# SS-302 · Booking message catalogue: every message in the driver's language, with the booking's link and code

As the Messaging component, I need every driver message to come from one catalogue of templates in English, Spanish
and Bengali, each message about a booking carrying that booking's link and code, so that a driver can read every
message and act on the booking straight from it.

## Acceptance criteria (EARS)
1. [Ubiquitous] The Messaging component shall send driver messages only from catalogue templates, apart from the free
   text an ops user writes (SS-314).
2. [Unwanted] If a template catalogue holds a driver message without an English, a Spanish or a Bengali text, then the
   Messaging component shall refuse to load that catalogue and keep the one in use (constitution N22).
3. [Ubiquitous] The Messaging component shall put in every message about a booking (confirmation, cancellation message,
   reminder, allocation, reallocation and rebooking notice, re-offer, alternatives, fault notice, site-full notice,
   keyword reply and cut-over message) a link that opens the driver page for that booking (SS-320) and the booking's
   code.
4. [Event] When the Messaging component renders a message, the Messaging component shall use the language stored for
   the recipient at that moment (SS-303), whatever the language of the recipient's phone or browser.
5. [Ubiquitous] The Messaging component shall show every booking time in a message in the site's time zone with the
   zone indicated (A-013).
6. [Event] When a booking's reminder falls due (SS-033), the Messaging component shall send the booking's charging
   driver, on the driver's channel (SS-308), one reminder naming the site, the start time and the booking code, with the
   booking's link.
7. [Unwanted] If a booking is no longer active when its reminder falls due, then the Messaging component shall send no
   reminder for it.
8. [Unwanted] If a reminder falls due for a slot the booking no longer has because it was rebooked, then the Messaging
   component shall send no reminder for that slot.
9. [Unwanted] If the reminder for the same booking and slot falls due more than once, for example after planned
   downtime, then the Messaging component shall send it once only.
10. [Unwanted] If a recipient's number is no longer registered to the booking's fleet, then the Messaging component
    shall send that number no message about the booking (A-052).

## Notes
- The reminder's timing (the site's lead time, A-011) and a booking made after its reminder point (#30) are SS-033;
  the timer for a rebooked slot is rescheduled by SS-032 (JS-224 S3). The booking code comes from #5 (SS-310).
- Native-speaker review of new Spanish and Bengali texts before each release: A-042. Language rules: SS-303; the PWA
  side of US-227 is SS-328.
- Clause 10 applies A-052 (working assumption for Q-045): a removed number gets no further messages about the fleet's
  bookings.
- Agreement gate SS-304; channel SS-308; delivery and resend SS-307.
- P3.4 (2026-10-28): clause 3 lists the cancellation message and rebooking notice added to SS-300 and SS-301; clause 6
  names the channel (JS-224 S1 "on their channel").
