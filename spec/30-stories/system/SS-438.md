# SS-438 · Amperlane engineers in the repositories, and a signed integration handover checklist

As the Platform & operations component, I need Amperlane's engineers to hold the same repository and tracker rights as
Intellias' engineers from Phase 0, work to count as done only once it is in Amperlane's repositories, and an integration
handover checklist that covers every production integration and records Priya Nair's sign-off per item, so that there
is no black-box handover.

## Acceptance criteria (EARS)
1. [Ubiquitous] The Platform & operations component shall give Amperlane's engineers the same roles in the
   repositories and the task tracker as Intellias' engineers, opening and reviewing changes included, from Phase 0.
2. [Ubiquitous] The Platform & operations component shall apply the same review rule to every change, whoever its
   author.
3. [Unwanted] If a task is marked done without a merged change in an Amperlane repository that Amperlane's engineers
   can see, then the Platform & operations component shall refuse the done status.
4. [Ubiquitous] The Platform & operations component shall build the integration handover checklist from the
   integrations running in production, so that an integration added after the checklist was drafted appears on it.
5. [Event] When Priya Nair records her sign-off of a checklist item, the Platform & operations component shall keep
   the sign-off with its date in the handover record.
6. [Unwanted] If an item of the checklist is not signed, then the Platform & operations component shall show the
   handover of that integration as open, naming the item.
