# SS-037 · Driver number registration in E.164, once per fleet, several fleets allowed

As the Fleet & vehicles module, I need to register drivers' mobile numbers to a fleet, by the fleet manager or by ops,
and answer at any moment whether a number belongs to a fleet, so that drivers book from the phone they already use and
only numbers the fleet registered can book its vehicles.

## Acceptance criteria (EARS)
1. [Event] When a fleet manager in the fleet portal, or ops on the fleet's behalf, registers a driver's mobile number
   for a fleet, the Fleet & vehicles module shall store it in E.164, list it among the fleet's drivers and report it as
   a driver of the fleet from that moment.
2. [Unwanted] If the number is not a valid phone number, then the Fleet & vehicles module shall not register it and
   shall name the number and the reason.
3. [Unwanted] If the number is already registered as a driver of the same fleet, then the Fleet & vehicles module shall
   create no second entry and say that the number is already registered.
4. [Event] When a number registered to another fleet is registered to this fleet, the Fleet & vehicles module shall
   register it to this fleet as well and answer without revealing anything of the other fleet.
5. [Ubiquitous] The Fleet & vehicles module shall answer, for a mobile number and a fleet, whether the number is a
   driver of the fleet, a booker-only number of the fleet or neither, as it stands at the moment of the query.

## Notes
- Covers US-302 S1, S3, S5 and S2 (clause 5: an unregistered number is neither, so SS-005 refuses its booking);
  US-301 S1 (drivers part), S3, S6; US-218 S1 and S5 (a number, not a device, is the identity; the driver's identity
  checks are SS-318).
- A-023, A-016, Q-028. A number entered without a country code is read as a North American number (+1), the only
  numbering plan of the launch metros; constitution code conventions row 12 (E.164).
- Another fleet's or another organisation's request (US-302 S4, US-301 S5) is refused by SS-323. Booker-only numbers:
  SS-042. Removal: SS-319 (REQ-202). Registration is not messaging consent (REQ-248, SS-304).
