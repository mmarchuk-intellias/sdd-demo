# SS-303 · Driver language preference: English, Spanish or Bengali, latest setting wins, English fallback

As the Messaging component, I need one stored language per driver, set by the fleet, ops or the driver and used for
everything the platform says to that driver, so that a Spanish- or Bengali-speaking driver understands every message
without a bilingual ops person.

## Acceptance criteria (EARS)
1. [Ubiquitous] The Messaging component shall store for each driver at most one language, which is English, Spanish
   or Bengali.
2. [Event] When a fleet user, an ops user or the driver sets a driver's language, the Messaging component shall
   replace the stored language with the new one, whoever set the earlier value, and use it for every message rendered
   from then on.
3. [Event] When a driver's language changes, the Messaging component shall send an audit event with the actor, the
   language before and after, and the time (SS-333).
4. [Unwanted] If a fleet portal, the ops console, a file import or the driver PWA submits a language other than
   English, Spanish or Bengali, then the Messaging component shall refuse it with the reason and keep the stored
   language.
5. [State] While a driver has no language stored, the Messaging component shall render every message to that driver
   in English, whatever the language of the driver's phone, browser or own messages.
6. [Ubiquitous] The Messaging component shall answer an inbound message in the sender's stored language, not in the
   language the inbound message is written in.
7. [Ubiquitous] The Messaging component shall resolve the language per recipient, so two people who get messages about
   the same booking each get them in their own language.
8. [Unwanted] If a driver's language changes after a message was sent, then the Messaging component shall not send
   that message again in the new language.

## Notes
- Settles bucket-5 item #34: the latest setting wins, whoever made it, and every change is in the audit trail.
- The language belongs to the driver's number, across all fleets it is registered to (A-016). English as fallback and
  English-only staff interfaces: A-042. The choices offered anywhere are the three of clause 1 (US-227 S6).
- The PWA uses the same stored language (SS-328); unclear messages and their acknowledgement are SS-312 (JS-217); the
  welcome is SS-306 (US-225 S3).
