# SS-229 · Completion evidence per booking and an ops-configurable completed definition

As the reporting module, I need to keep for every booking the evidence any candidate definition of "completed" needs,
and count completed bookings by a definition ops can change without a deployment, so that the north-star figure
follows whatever definition the founders choose (Q-017).

## Acceptance criteria (EARS)
1. [Ubiquitous] The reporting module shall keep for every booking its state, its arrival (kind and time), its
   session-record match with energy, its rebooks, and the reason code of each of its state changes, taken from the
   owning modules' events.
2. [Ubiquitous] The reporting module shall count completed bookings by the configured completed definition, a rule over
   the fields of clause 1 only, whose default is the Completed state.
3. [Event] When an ops user changes the completed definition, the reporting module shall count completed bookings under
   the new definition from the next report, with no deployment.
4. [Unwanted] If a definition uses anything other than the booking's state, arrival, session-record match, energy,
   rebooks and reason codes, then the reporting module shall refuse it and keep the current definition in force.
5. [Unwanted] If a user without the Amperlane ops role tries to change the completed definition, then the reporting
   module shall refuse the change.
6. [Event] When evidence for a booking arrives later, such as a session-record match, the reporting module shall
   re-evaluate the booking under the definition in force and count it once it qualifies.
7. [Ubiquitous] The reporting module shall state with every completed-booking figure the definition it was counted
   under.
8. [Optional] Where the completed definition counts rebooked bookings, the reporting module shall count a rebooked
   booking that charged as completed and never the no-show booking it followed.
9. [Optional] Where the completed definition excludes rebooked bookings, the reporting module shall count neither the
   rebooked booking nor the no-show booking it followed as completed.
10. [Event] When an ops user changes the completed definition, the reporting module shall record the change with the ops
    user and the time.
