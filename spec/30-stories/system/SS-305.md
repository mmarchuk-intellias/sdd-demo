# SS-305 · Consent texts and fee notices: versions in three languages, acceptance stored

As the Messaging component, I need to hold every consent text and fee notice as versions in English, Spanish and
Bengali, and to keep exactly which version and language each driver accepted, so that a driver agrees only to wording
they could read and is never held to wording they did not see.

## Acceptance criteria (EARS)
1. [Ubiquitous] The Messaging component shall keep each consent text and fee notice as numbered versions, each with an
   English, a Spanish and a Bengali text.
2. [Unwanted] If a version lacks its English, Spanish or Bengali text, then the Messaging component shall keep serving,
   in place of it, the latest version that has all three texts.
3. [Event] When the driver PWA asks for a consent text or fee notice for a driver, the Messaging component shall
   return the latest published version in the driver's stored language (SS-303).
4. [Event] When a driver accepts a consent text or fee notice, the Messaging component shall store the text, its
   version, the language shown and the time against that driver.
5. [Unwanted] If a driver closes a consent text or fee notice without accepting it, then the Messaging component shall
   report the purpose it covers as not agreed for that driver, with no acceptance stored, so location stays off (A-024).
6. [Unwanted] If an acceptance names a version that is not published, or a language other than the one served to that
   driver, then the Messaging component shall refuse it and store nothing.
7. [Ubiquitous] The Messaging component shall never change a stored acceptance: a later language change, a new version
   or a new acceptance adds a record and leaves earlier ones as they were.

## Notes
- Counsel approves the wording (A-024; Q-016 for the consent basis). Fee notice content depends on Q-002 (who pays);
  this SS does not assume the payer.
- Whether a driver must accept a new version before the purpose it covers continues is Q-057, a client decision; no
  clause assumes an answer (clause 7 only keeps earlier acceptances unchanged, US-230 S5).
- Location opt-in itself is guarded by SS-341. If the agreement to booking messages is captured as a consent text, it
  is also recorded by SS-304. Retention of acceptances follows A-025 (SS-336).
