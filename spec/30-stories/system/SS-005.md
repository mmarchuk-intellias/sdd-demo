# SS-005 · Booker and charging driver recorded on every booking

As the Booking engine, I need to record on every booking a charging driver registered to the vehicle's fleet and a
booker allowed to book for that fleet, so that the booking and its messages belong to the person who will charge,
whoever made it.

## Acceptance criteria (EARS)
1. [Ubiquitous] The Booking engine shall record on every booking, except a booking carried over at cut-over (SS-003
   clause 9), one charging driver, who is a mobile number registered as a driver of the fleet of the booking's vehicle,
   and one booker.
2. [Event] When a number registered as a driver of the vehicle's fleet books without naming anyone else, the Booking
   engine shall record that number as both booker and charging driver.
3. [Event] When a number registered to the vehicle's fleet, as a driver or as a booker-only number, books and names
   another number registered as a driver of that fleet, the Booking engine shall record the booking number as booker
   and the named number as charging driver.
4. [Event] When a fleet-portal user books for a vehicle of the user's own fleet, the Booking engine shall record that
   user as booker, and as the actor of the booking's confirmation in its history (SS-020), and the named driver as
   charging driver, and apply to the booking the same grid, cap, compatibility, pool and hold rules as to a driver's
   own booking.
5. [Unwanted] If a booker-only number books without naming a charging driver, then the Booking engine shall refuse
   the request with the code CHARGING_DRIVER_REQUIRED and place no hold.
6. [Unwanted] If the named charging driver is not registered as a driver of the fleet of the booking's vehicle (a
   booker-only number, a number registered only to another fleet, or a number the fleet removed), then the Booking
   engine shall refuse the request with the code CHARGING_DRIVER_NOT_IN_FLEET and place no hold.
7. [Unwanted] If the number that books is not registered to the fleet of the booking's vehicle, as a driver or as a
   booker-only number, at the moment of the request, then the Booking engine shall refuse the request with the code
   BOOKER_NOT_IN_FLEET and place no hold.
