# SS-425 · Production in an AWS account separate from every other environment

As the Platform & operations component, I need production in an AWS account of its own, apart from every non-production
environment, so that no test, staging or developer workload or credential can reach production systems or data.

## Acceptance criteria (EARS)
1. [Ubiquitous] The Platform & operations component shall run production in an AWS account that holds no
   non-production environment, and each non-production environment in another account, all defined in Terraform.
2. [Unwanted] If a Terraform plan for a non-production environment targets the production account, or the production
   plan targets another account, then the Platform & operations component shall fail the pipeline run and apply
   nothing.
3. [Unwanted] If a role, credential or network path of a non-production account tries to read or change a production
   resource, then the Platform & operations component shall refuse it.

## Notes
- Enabler: REQ-124 has no story. Constitution N13; ADR-012.
- Staging reaches only sandboxes and simulators (SS-435). Production data leaves production only as de-identified
  copies (REQ-118, SS-339); the full export stays in the production account (SS-434).
