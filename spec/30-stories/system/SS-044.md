# SS-044 · Optional manual SoC reading, with no vehicle data needed to book

As the Fleet & vehicles module, I need to store a state of charge a driver chooses to enter while booking and never
require any vehicle data to book, so that a cab with no telematics books as easily as any other vehicle and a driver
can still report the battery level in the booking flow.

## Acceptance criteria (EARS)
1. [Event] When a booking request carries a manual state of charge between 0 and 100 percent, the Fleet & vehicles
   module shall store it as a reading for the booking's vehicle with the source 'manual', the booking and the time,
   and return it with the booking.
2. [Unwanted] If a manual state of charge is not a number or is outside 0 to 100 percent, then the Fleet & vehicles
   module shall refuse the value with a reason and store nothing, and the booking can still be confirmed without it.
3. [Ubiquitous] The Fleet & vehicles module shall answer the Booking engine's vehicle checks without needing a state of
   charge, a location or any telematics data, so a vehicle with no telematics link or no data is booked on the same
   terms as any other vehicle.
4. [Ubiquitous] The Fleet & vehicles module shall not give a manual state of charge to any booking, allocation or fee
   decision.

## Notes
- Covers US-012 S1 – S3 (S4, two taps, is SS-326); US-213 S1, S4 and S5 (S2 is SS-311; S3, no location without
  opt-in, is SS-331 and SS-341).
- No K or Y requirement uses the entered SoC; suggesting a duration from it is REQ-017 (I). REQ-018 stays Y for the
  "Geotab plus manual SoC" cut (CTX-099); its final KYIV is a Step 5 input.
- The SoC is vehicle data in the data register (constitution SC4).
