# SS-131 · No-show fee decision: one fee request, or ops review for excluded bookings

As the Arrival & no-show component, I need to decide, for each booking released after grace with no arrival, whether one
no-show fee line is created at once or the booking goes to ops for a decision, so that station operators are paid for
EVSEs held for drivers who never came and no driver is charged for a failure of the platform or the site.

## Acceptance criteria (EARS)
1. [Event] When a booking is released after grace with no arrival and none of the exclusions of clause 2 applies, the
   Arrival & no-show component shall request exactly one no-show fee line for it (SS-401) at the fee amount and station
   share fixed for it at confirmation (SS-027).
2. [Event] When a booking is released after grace with no arrival and it was rebooked, its station hold failed (SS-119,
   SS-123, SS-133), its site was full or faulted (SS-105, SS-109), its reminder was reported undelivered (SS-307) or its
   grace timer fired late (SS-127), the Arrival & no-show component shall request no fee line and raise a 'fee decision'
   ops exception for it (SS-219) that names each exclusion that applies.
3. [Event] When an ops user decides the fee of an excluded booking with a reason code from the catalogue, the Arrival &
   no-show component shall request exactly one fee line at the booking's fixed terms if ops create the fee, or none if
   ops waive it, record the decision with the ops user, the reason code and the time, and mark the exception resolved.
4. [Unwanted] If an ops user's fee decision has no reason code from the catalogue, then the Arrival & no-show component
   shall refuse it and keep the booking in the queue.
5. [Unwanted] If the release of a booking is processed more than once, then the Arrival & no-show component shall
   request no more than one fee line for it.

## Notes
- Contract (ss-plan §5.1): this SS decides; SS-401 records exactly one fee line separate from energy (constitution N19);
  SS-027 fixes the terms at confirmation (bucket-5 item 17); reversals and waivers after a line exists are SS-402.
- A-019 (site full), A-028 (late timers), Q-002 (payer undecided; the line exists in every option), Q-005 (amounts). A
  late cancellation (A-049) reaches the same exception through SS-132; a force-release never creates a fee automatically
  (SS-016, item 23); a running-late report is no exclusion (SS-129).
- US-109 S5 (release at the end of an extension) is clause 1 with SS-127.
