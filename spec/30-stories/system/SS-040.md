# SS-040 · Ops onboarding of a fleet and handover to a fleet manager

As the Fleet & vehicles module, I need ops to create a fleet and register its drivers and vehicles without any portal
user, and a fleet manager to take over that data later, so that a fleet that will not use a portal can book from
launch day and a fleet that later wants the portal does not start from scratch.

## Acceptance criteria (EARS)
1. [Event] When ops create a fleet in the ops console, the Fleet & vehicles module shall create it with no fleet portal
   user and accept driver numbers, booker-only numbers and vehicles for it from ops, with no portal sign-in at any step.
2. [Ubiquitous] The Fleet & vehicles module shall list for ops the drivers, booker-only numbers and vehicles of every
   fleet.
3. [Event] When a person of the fleet is given a fleet manager login, the Fleet & vehicles module shall show that fleet
   manager every driver number, booker-only number and vehicle registered for the fleet, the ones ops registered
   included, with the same rights to add, edit and retire them as for those the fleet manager registers.
4. [Ubiquitous] The Fleet & vehicles module shall change no registration and no booking of a fleet when a fleet manager
   takes over, and keep the actor who made each registration.
5. [Unwanted] If ops create a fleet without a name, or with the name of an existing fleet, then the Fleet & vehicles
   module shall refuse it.
6. [Ubiquitous] The Fleet & vehicles module shall keep for each fleet one billing contact, a name and an e-mail
   address, which ops enter when they create the fleet and can change, and give it to Ledger & invoicing for the
   fleet's invoices.
7. [Unwanted] If ops create a fleet without a billing contact, or with a billing e-mail address that is not valid,
   then the Fleet & vehicles module shall refuse it and store no fleet.
