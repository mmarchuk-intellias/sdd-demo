# SS-118 · Site-staff station-hold request: stall, mark and clear times, delivery-failure exception

As the Station-hold dispatcher, I need to tell site staff, for each booking without a charger reservation, which stall
to mark, when to mark it and when to clear it, and to alert ops when the request cannot be delivered, so that the right
stall is held at the right time without ops phoning the site.

## Acceptance criteria (EARS)
1. [Event] When the site's configured station-hold offset before the slot start of an active allocated booking is
   reached, its EVSE is not flagged reservable and the site is not in manual mode (SS-123), the Station-hold dispatcher
   shall send site staff a station-hold
   request naming the stall to mark, the time to mark it and the time to clear it (the booking's end of grace unless the
   driver has arrived), with the system as actor.
2. [Optional] Where a site's staff receive station-hold requests by SMS, the Station-hold dispatcher shall send each
   request through Messaging to the site's registered staff number, count it delivered on the provider's delivery
   report, and take an SMS reply from that number that names the request as its acknowledgement.
3. [Optional] Where a site's staff use the attendant view, the Station-hold dispatcher shall show each request in the
   attendant view (SS-228), count it delivered once the attendant view has loaded it, and take the attendant's
   confirmation there as its acknowledgement.
4. [Event] When site staff acknowledge a station-hold request, the Station-hold dispatcher shall record the
   acknowledgement with its time and mark the booking's station hold as placed.
5. [Unwanted] If a station-hold request is not delivered within the site's configured site-staff delivery timeout, then
   the Station-hold dispatcher shall raise a 'station-hold request undelivered' ops exception for the booking (SS-219).
6. [Unwanted] If a booking is cancelled or released before its station-hold offset, then the Station-hold dispatcher
   shall send no station-hold request for it.
7. [Unwanted] If the allocated EVSE is in use (occupied or charging) when its station-hold request falls due, then the
   Station-hold dispatcher shall send no request for that EVSE and leave the booking to reallocation or site-full
   handling (SS-104, SS-105).
8. [Event] When a booking's end of grace changes after its station-hold request was sent (SS-130), the Station-hold
   dispatcher shall send site staff the new time to clear the stall on the request's channel.
9. [Ubiquitous] The Station-hold dispatcher shall put in a site-staff request no driver data beyond the vehicle's plate
   and the charging driver's first name.
