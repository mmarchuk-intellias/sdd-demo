# SS-237 · Ops console capacity-rule saves: one idempotency key per form, repeated on every resend

As the ops console, I need to send one idempotency key with each capacity-rule change an ops person saves for a station
operator and the same key again whenever that change is sent again from the same form, so that a save repeated after a
lost response changes the site's capacity rules once.

## Acceptance criteria (EARS)
1. [Ubiquitous] The ops console shall send an idempotency key with every capacity-rule change it submits.
2. [Unwanted] If a capacity-rule change is sent again from the same form, by the ops person or by a retry after no
   response arrived, then the ops console shall send the same idempotency key as with the first save.
3. [Event] When an ops person opens a new capacity-rule form, the ops console shall use a new idempotency key for the
   change submitted from it.
