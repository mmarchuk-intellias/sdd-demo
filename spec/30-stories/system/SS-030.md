# SS-030 · EVSE connector records with type and maximum power

As the Inventory & site configuration module, I need every EVSE connector recorded with a connector type from a fixed
list and its maximum power, so that compatibility and allocation never run on free text or a missing power value.

## Acceptance criteria (EARS)
1. [Ubiquitous] The Inventory & site configuration module shall record for each EVSE one or more connectors, each with
   a connector type, CCS1 or NACS, and a maximum power in kW.
2. [Unwanted] If a connector is saved with a type other than CCS1 or NACS, for example the pilot's free text "CCS", or
   without a positive maximum power, then the Inventory & site configuration module shall refuse it and keep the
   records already saved, which bookings keep being matched against.
3. [Unwanted] If an EVSE is saved with no connector, then the Inventory & site configuration module shall refuse it.
4. [Ubiquitous] The Inventory & site configuration module shall accept connectors of both types on one EVSE.
5. [Event] When a connector record changes, the Inventory & site configuration module shall report the new type and
   power to every compatibility and allocation check made after the change.

## Notes
- Covers US-006 S6 (connector side; the vehicle side is SS-038), the records behind S1 and S5.
- A-004 and Q-013: whether an EVSE carries two connector types at the pilot sites, and how ports, chargers and stalls
  map to EVSEs. Compatibility is SS-004; the power choice at allocation is SS-101 (REQ-016).
