# SS-423 · Pre-launch real-booking period and go-live record

As the Pilot migration & cut-over component, I need a go-live record that shows, per pilot site, the real bookings run
end to end in the platform during the configured pre-launch real-booking period and the evidence against each written
go-live criterion, and that accepts the approval to switch off the Amperlane Concierge only when every criterion is met,
so that the pilot is switched off on evidence rather than on the calendar.

## Acceptance criteria (EARS)
1. [Ubiquitous] The Pilot migration & cut-over component shall keep a go-live record holding the written go-live
   criteria and, for each of Gowanus, JFK and LIC, the real bookings run end to end in the platform during the
   configured pre-launch real-booking period, with the evidence against each criterion.
2. [Ubiquitous] The Pilot migration & cut-over component shall count as real only bookings of registered drivers of the
   pilot fleets whose numbers are not on the staff list of Amperlane and Intellias people.
3. [Unwanted] If a pilot site has no real booking run end to end in the pre-launch period, then the Pilot migration &
   cut-over component shall show that site as not proven.
4. [Unwanted] If the switch-off of the Amperlane Concierge is submitted for approval while any written criterion is not
   met or any pilot site is not proven, then the Pilot migration & cut-over component shall refuse the approval and
   list each open criterion and each site not proven.
5. [Event] When a named approver approves the switch-off with every criterion met, the Pilot migration & cut-over
   component shall record the approval with the approver, the time and the evidence for each criterion.
6. [Ubiquitous] The Pilot migration & cut-over component shall count as run end to end only bookings made, allocated,
   given their station hold and closed in the platform.
7. [Event] When another component reports evidence against a written go-live criterion, such as the status of the
   breach-notification procedure (SS-338 clause 8), the Pilot migration & cut-over component shall record that evidence
   against the criterion in the go-live record.
