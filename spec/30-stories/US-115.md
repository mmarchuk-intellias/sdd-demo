As Amperlane ops, I want to waive a no-show fee with a reason code before it is invoiced, so that a fee we agree was
unfair never reaches the fleet's invoice.

## Acceptance criteria

Scenario: S1 · happy path · A waiver before invoicing
  Given a no-show fee line that is not on an issued invoice
  When an ops user waives it with a reason code
  Then a separate ledger entry records the waiver with the ops user, the reason code and the time
  And the original fee line is unchanged
  And the fee is not charged on the fleet's next invoice

Scenario: S2 · failure · A waiver without a reason code is refused
  Given a no-show fee line that is not on an issued invoice
  When an ops user tries to waive it without a reason code
  Then the waiver is refused

Scenario: S3 · failure · An invoiced fee cannot be waived
  Given a no-show fee line that is on an issued invoice
  When an ops user tries to waive it
  Then the waiver is refused
  And the issued invoice is unchanged

Scenario: S4 · failure · A user who is not Amperlane ops cannot waive
  Given a fleet manager is signed in to the fleet portal
  When the fleet manager tries to waive a no-show fee of the fleet
  Then the waiver is refused

Scenario: S5 · edge case · A fee cannot be waived twice
  Given a no-show fee was already waived
  When an ops user waives it again
  Then no second waiver entry is recorded

Scenario: S6 · edge case · Energy lines stay untouched
  Given a booking has an energy line and a no-show fee line
  When an ops user waives the no-show fee
  Then the energy line is unchanged

## Notes

- Q-002: the payer is undecided; the waiver holds in every option.
- The ledger is double-entry and append-only (REQ-085, REQ-247; constitution N19). An invoiced fee is reversed through
  a dispute decision with a credit line on the next invoice (US-113, REQ-213).
