# US-225 · A welcome message when a driver's number is registered

As a newly registered driver, I want a welcome message in my language that tells me how to book, cancel and report
running late, so that I can use Amperlane from my first shift without installing anything or being walked through it
by ops.

## Acceptance criteria

Scenario: S1 (happy path) A driver is registered
  Given Borough Green registers a driver's mobile number with the language Spanish
  And the driver's agreement to booking messages is recorded
  When the registration is saved
  Then the driver receives one welcome message in Spanish
  And it explains how to book, how to cancel and how to report running late

Scenario: S2 (failure) No agreement to messages is recorded yet
  Given a driver's number is registered
  And no agreement to booking messages is recorded for the driver
  When the registration is saved
  Then no welcome message is sent
  And the welcome message is sent once the agreement is recorded

Scenario: S3 (failure) No language is set
  Given a driver's number is registered with no language set
  When the welcome message is sent
  Then it is in English

Scenario: S4 (edge case) The same number is registered again
  Given a driver's number is already registered to Borough Green and was welcomed
  When Borough Green registers the same number again, for example by re-importing its driver file
  Then no second welcome message is sent

Scenario: S5 (edge case) The driver replies STOP to the welcome
  Given a driver received the welcome message by SMS
  When the driver replies STOP
  Then the driver receives no further SMS from Amperlane (REQ-248)

## Notes

- Registration by the fleet, or by ops for small fleets, is A-023 (REQ-205, REQ-206, FT-08.1).
- S2 depends on REQ-248 (US-229). How the driver's agreement is given and recorded before the first message (the fleet
  records it at registration, the driver texts first, or something else) is Q-056; S2 holds under any answer. Q-047
  covers the carrier registration only.
- Whether a driver already registered to one fleet gets a welcome when a second fleet registers the same number is a
  design detail for Step 3.3.
- Language rules: REQ-199 (US-227).
