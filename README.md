# Amperlane platform: spec repository

Spec-driven presale for Amperlane, Inc.
The spec is the primary artefact; agents follow [AGENTS.md](AGENTS.md) (Claude Code loads it through `CLAUDE.md`).

## Layout

```
sdd-demo/
├── AGENTS.md                       # agent operating rules + project specifics
├── CLAUDE.md                       # loads AGENTS.md into Claude Code
├── README.md
├── spec/
│   ├── constitution.md             # NFR baseline, DoR/DoD, conventions, KYIV rules (empty until Step 2.2)
│   ├── 00-inputs/                  # original materials, READ-ONLY
│   │   ├── D1_Amperlane_Platform_Partner_Brief_Sep2026.pptx            → SRC-D1
│   │   ├── C1_Amperlane_Call1_Discovery_Transcript_2026-09-29.docx     → SRC-C1
│   │   ├── C2_Amperlane_Call2_Tech_DeepDive_Transcript_2026-10-08.docx → SRC-C2
│   │   ├── D2_Intellias_Amperlane_Solution_Direction_Oct2026.pptx      → SRC-D2
│   │   ├── R1_Amperlane_Client_Recap_Oct2026.html                      → SRC-R1
│   │   └── _extracted/             # plain-text extracts (generated by tools/extract.py)
│   │       ├── _index.md           # source register: IDs, origin, anchors, sha256
│   │       └── <same name>.md      # one per input, with slide numbers / timestamps / anchors
│   ├── 01-context/                 # Step 1: business context, glossary, stakeholders, conflicts, questions
│   ├── 10-design/                  # Step 1 (v0), revised after Step 3: design, data model, integrations, ADRs
│   ├── 20-requirements/            # Step 2: requirements.md
│   ├── 30-stories/                 # Step 3: epics.md, US-/JS-###.md, system/SS-###.md
│   ├── 40-tasks/                   # Step 4: tasks.md, tasks.yaml
│   └── 90-trace/                   # GENERATED by tools/trace.py, never edited by hand
│       ├── trace.csv
│       └── coverage-report.md
└── tools/
    ├── extract.py                  # inputs → _extracted/ (stdlib only)
    └── trace.py                    # front-matter → trace.csv + coverage-report.md
```

## Commands

```sh
uv venv && uv pip install -r requirements.txt   # one-time: .venv with PyYAML (VS Code picks it up)
python3 tools/extract.py     # regenerate extracts after a new input lands in spec/00-inputs/
uv run tools/trace.py        # rebuild trace.csv and coverage-report.md (PyYAML via uv)
uv run tools/trace.py --check   # CI: write nothing; fail on K gaps or stale generated files
```
